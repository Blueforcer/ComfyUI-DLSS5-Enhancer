# DLSS5 增强图像

DLSS5 增强图像节点在原生 worker 上对每张图像执行 NVIDIA DLSS 5 神经渲染（NGX feature 18）。按播放顺序输入视频帧，使时间累积生效。

## 输入

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `图像` | IMAGE | 按播放顺序的帧；批量顺序即时间顺序。 |
| `设置` | DLSS5_SETTINGS | 连接一个 DLSS5 Settings 节点。 |
| `校验神经渲染` | BOOLEAN | 当 ReShade 日志显示没有带签名的 feature-18 执行时使渲染失败，而不是静默返回普通放大的帧。 |

## 输出

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `图像` | IMAGE | 经过 DLSS 5 神经渲染重构后的帧。 |
