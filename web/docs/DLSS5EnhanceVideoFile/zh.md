# DLSS5 增强视频文件

DLSS5 增强视频文件节点解码视频文件，对每一帧执行 NVIDIA DLSS 5 神经渲染后重新编码，保留原始时间戳、音频、章节和元数据。长视频不会作为批量进入工作流。

## 输入

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `视频路径` | STRING | 源视频文件的绝对路径。 |
| `设置` | DLSS5_SETTINGS | 连接一个 DLSS5 Settings 节点。 |
| `编码器` | COMBO | H.264 与 HEVC 使用 NVENC 并带软件回退。AV1 需要 NVENC 且无回退。ProRes Proxy 为软件编码。 |
| `容器` | COMBO | MKV 直接复制音频和字幕。MP4 与 MOV 将音频转码为 AAC 并丢弃字幕。ProRes 需要 MOV 或 MKV。 |
| `质量` | COMBO | Auto 根据分辨率和帧率推导码率，Good 翻倍，Best 四倍，Max 以恒定质量编码。ProRes Proxy 忽略此设置。 |
| `文件名前缀` | STRING | 输出文件的前缀；会追加时间戳。 |
| `输出目录` | STRING | 留空写入 ComfyUI 输出目录。相对路径在其内解析；绝对路径按原样使用。 |
| `最大帧数` | INT | 0 渲染整段视频；其它值渲染该帧数的预览。 |
| `复制音频` | BOOLEAN | 将原始音频（MKV 时连同字幕）封装进结果。章节和元数据始终保留。 |
| `校验神经渲染` | BOOLEAN | 渲染后检查 ReShade 日志中是否带签名的 feature-18 执行。无论是否通过都会写入文件。 |

## 输出

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `视频路径` | STRING | 重新编码后的输出视频路径。 |
| `帧数` | INT | 实际渲染的帧数。 |
