# DLSS5 设置

DLSS5 Settings 节点集中配置 NVIDIA DLSS 5 神经渲染的全部参数，供「DLSS5 增强图像」或「DLSS5 增强视频文件」节点使用。一个设置节点可同时喂给图像和视频增强节点。

## 输入

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `放大模式` | COMBO | DLSS 模式。1x（DLAA）在源分辨率上增强；其它模式同时按该倍数放大。 |
| `NR 预设` | COMBO | DLSS 模型内部的神经渲染预设。实测在当前构建上每个值输出相同。 |
| `NR 风格` | COMBO | 神经渲染的观感：Natural 更贴近源图，Cinematic 更强。 |
| `NR 强度` | FLOAT | 神经渲染的整体强度。实测当前运行时高于 1.0 无更多效果；低于 1.0 用于向源图回混。 |
| `局部色调强度` | FLOAT | 局部色调映射强度。 |
| `局部结构强度` | FLOAT | 局部细节与结构重建强度。数值越高保留越多纹理；1.5 对 AI 生成内容是比较好的平衡。 |
| `皮肤结构强度` | FLOAT | 皮肤与毛孔重建。依赖「自动遮罩」（它告诉模型哪里是皮肤）；关掉遮罩时此参数无效。-1 交给模型自行决定。 |
| `自动遮罩` | BOOLEAN | 让模型自动识别当作皮肤处理的区域，同时是「皮肤结构强度」的开关。 |
| `DLSS 模型预设` | COMBO | 强制使用特定 DLSS 模型而非 NVIDIA 默认。实测细节保留：Default、J、K 最柔和，L、M 能重建明显更多的皮肤与毛发纹理。若 worker 报告应用的预设不同，请设为 Default。 |
| `运动模式` | COMBO | 用于时间累积的运动向量。auto 对序列自动估计光流，对单张图跳过。 |
| `场景切换阈值` | FLOAT | 平均亮度变化超过该值时重置时间历史。 |
| `预热帧` | INT | worker 在首个输出稳定前额外渲染的帧数。 |
| `运行时目录` | STRING | 可选的 DLSS 5 运行时目录（含 nvngx.dll 的文件夹）。留空则按 config.json、环境变量 DLSS5_RUNTIME_DIR 或内置 runtime 文件夹的顺序查找。 |

## 输出

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `设置` | DLSS5_SETTINGS | 配置好的一套会话参数，传给增强节点使用。 |
